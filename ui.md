# UI/UX Specification & Design Guidelines (`ui.md`)

* **Core Identity & Directives**
  * **Mandatory Constraint 1 (No AI Slop):** Strictly prohibit generic AI-generated design clichés. This means **zero** arbitrary glowing neon gradients on dark backgrounds, **zero** floating glassmorphism cards with random blur effects, **zero** meaningless decorative background blobs/grids, and **zero** bloated wrapper components and no icons like sparkle rocket or anything (all those ai slop icons) like that basically no icons from that lucide or react icon library or any other library, obviously the important icons like phone, emails, etc can be there. Every visual element, container, and effect must have an explicit functional justification.
  * **Mandatory Constraint 2 (Absolute Responsiveness):** Every component, layout, and view must be rigorously tested and engineered mobile-first. Layouts must scale fluidly from 320px mobile viewports to ultra-wide displays without horizontal overflow, cramped text, or broken grids.
